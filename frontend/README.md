# Frontend React - ClimaGuru

Cliente React para autenticacion y CRUD de usuarios usando API Flask.

## Estructura

- src/
- components/
- services/

## Configuracion

1. Copia `.env.example` a `.env`
2. Ajusta `VITE_API_BASE_URL` si corresponde

## Ejecutar

```bash
cd frontend
npm install
npm run dev
```
